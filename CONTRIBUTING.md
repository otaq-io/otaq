# Contributing to Otaq

Thanks for your interest in Otaq.

## Pull requests

**Otaq doesn't accept pull requests from outside the Otaq team for now.** A pull request from someone without
write access to this repository is closed automatically, unread. This isn't about the quality of your work: the
product is changing quickly, and we can't review and maintain outside changes yet. We'll update this file when that
changes.

## What helps

- **Bug reports.** [Open an issue](https://github.com/otaq-io/otaq/issues/new) with your system (macOS, Windows or
  Linux), the Otaq version, the agent tool you use (Claude Code, Codex, Copilot or OpenCode), what you did, what you
  expected and what happened. Logs and screenshots help.
- **Ideas and feature requests.** Open an issue that describes the problem you want solved, not only the solution.
- **Security problems.** Don't open a public issue. Report them privately through
  [GitHub's security advisories](https://github.com/otaq-io/otaq/security/advisories/new).

If an issue would be easiest to explain with code, describe the change in the issue, or link to a branch in your
fork. We may write it ourselves.
