# 062 · A skill bundle carries only Otaq's own skills

- **Date:** 2026-11-14
- **Status:** Accepted
- **Related:** 061, 063

## Summary

A stage that names the user's own skill runs that skill as before: no bundle adds, changes or removes a user's skill.

## Decision

- Releases hold only Otaq's workflow skills, the tuq skills and the `tuq` commands (decisions 057, 077). A user's skills stay where the user keeps them, untouched.

## Why

The user's custom flow must not be affected by Otaq's skill updates. Was S14.
